# WKFLのX運用

X @wkflstudio に関する継続的な要望、文体の指針、投稿原稿、公開結果の拠点。

## 文案を書く前に

1. [文体とユーザーの要望](STYLE.md)を毎回開く。
2. [配信手順](../../playbooks/publishing.md)と今回の依頼範囲を確認する。
3. 元の発言から文案を作り、指針に照らして読み返す。

## 残すもの

- `STYLE.md`: 繰り返し役立つ文体の要望と、本人の評価を受けたサンプル。指摘のたびに該当箇所を更新する。
- `drafts/`: 進行中の原稿と、必要な調査メモ。個別の仮説はその企画に紐づける。
- `posted/history.json`: 公開・削除の結果と投稿URL。文体の見本としての採用状況とは別に管理する。
- `list/`: 参照用の取得データ。

残す情報は、次の投稿でも必要になる要望、採用された表現、作業の再開に必要な状態を選ぶ。作業中の会話をそのまま蓄積する代わりに、既存の記述へ要点を反映する。
