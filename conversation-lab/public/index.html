Gemini 3.8 Live の仕様

確認日：2026-10-11。提供条件・モデル名は変更される可能性があります。

モデル / 接続
gemini-3.8-live / v1beta WebSocket / サーバー経由
日本語・入出力
日本語対応。モデルはテキスト・音声・画像・動画入力に対応。本アプリは音声入力と指示テキスト、音声応答と文字起こしを使用。応答モダリティはAUDIO。
音声形式
PCM 16bit little-endian mono。入力16 kHz・モデル出力24 kHz。本アプリの会話録音は共通16 kHz。
声
Kore / Puck / Charon / Aoede を選択可能な候補として登録。全声・日本語品質の実機確認は未完。
発話・割込み
自動VAD（本アプリの無音閾値700ms）、または手動区切り。割込み通知で再生を停止。Gemini 3.8 Liveのproactive audioは常時有効。
コンテキスト
入力131,072 / 出力65,536 tokens。モデルの仕様上限であり、アプリの利用保証ではありません。
時間制限
公式：圧縮なし音声のみ15分、音声＋動画2分。接続は約10分。本アプリ：既定60秒、最大180秒。圧縮・再開・自動再接続は未実装。
現在の対象外
動画、ツール、Search grounding、声の複製、公開閲覧・認証。thinking設定は送信しません。
