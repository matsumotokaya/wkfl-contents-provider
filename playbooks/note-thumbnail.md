# noteのサムネイル（見出し画像）を画像生成で作る

この文書が答える問い: noteのサムネをどう作るか。サイズ、使う道具と鍵、費用、プロンプトの書き方、生成で変わってしまうもの、過去の作例と判断。

対象: 個人プロジェクト WKFL。最終確認: 2026-10-08。

## サイズ

noteの見出し画像は**縦横比 1.91:1 だけ合わせる**（推奨は 1280×670）。`--size 2560x1344` で生成し、縮小せずそのまま入稿する（2026-10-08 ユーザー判断）。

## 道具と作業場所

- `tools/image_fal.py` — fal経由の gpt-image-2.5（`openai/gpt-image-2.5/sunburst/edit`）。使い方は冒頭の docstring。gen-video の `src/image-fal.ts` からの移植
  - OpenAI直だと組織認証がなく 403 になるため fal を使う
  - 鍵は `~/.secrets/fal-token`（gen-video と同じ fal アカウント）
  - high・2560×1344 で1枚約 $0.09（定価からの見積り。実額は fal のダッシュボード）、35〜70秒
  - 実行記録は `tools/ledger/`。リポジトリが公開なので git には入れない
- 作業は `media/note/thumbnail/<日付>_<題材>/` に `inputs/` `prompts/` `takes/` `final/`（`media/note/` は git 管理外）。採用は `final/` へ移し、不採用はゴミ箱へ

## 進め方

- 見た目（YouTube風・雑誌風など）は**毎回ユーザーと決める**。スタイル集は作らない方針
- 文言は記事の事実から作る。数字は記事を数えて入れる（例: 失敗の節の数、付録プロンプトの本数）
- 生成は方向が決まってから1枚。別案・作り直しは事前にユーザーに確認する

## プロンプトの書き方（2026-10-08 に3枚で効いたもの）

- 指示は英語。画像内の文字は `"日本語"` の引用で原文どおり書き、番号付きで位置・色・装飾まで指定する。7〜9要素でも誤字なしで出た
- 末尾に `The only text in the image is the quoted text above, each appearing once.` を置く
- 残したい被写体は具体物で名指しする（結晶の形・ヒビ・条線・色・岩・被写界深度）。「スタイルを保て」は効かない（gen-video `docs/restage.md`）

## 生成で変わってしまうもの

- **被写体は描き直される。** 形と配置はほぼ保つが、ヒビ・条線などの細部は別物になる。画素一致はしない
- そのため「画像生成AIじゃない」のように、**サムネ自体と矛盾する文言は載せない**
- ワイヤーフレームやクレイ表示も gpt-image で描ける。ただし線は実際のメッシュと一致しない（イメージ図）。実物が要るときは blender-mineral 側で Blender MCP 経由で書き出す（別プロセスで Blender を起動するのは同プロジェクトのルールで禁止）

## 予定

画像生成の道具と汎用の教訓は、全プロジェクト共通の skill（`~/.agents/skills/`）に移す予定（エンジン層のみ。スタイルは含めない）。移したら「道具と作業場所」を差し替える。
