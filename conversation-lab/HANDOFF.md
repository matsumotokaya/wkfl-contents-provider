# Conversation Lab 仕様・引き継ぎ

対象：WKFL内の `conversation-lab/`。この文書が答える問い：何を研究するか、どこまで実装・確認したか、どこから開発を再開するか。記録日：2026-10-11。

## 目的と境界

WKFLのコンテンツ制作に、リアルタイムAI対談の研究を加える。代表的な声・モデル、日本語会話例、反応速度・コストを比較するカタログを育て、録音と研究結果をpodcast/YouTubeへ再利用する。現在は本人だけが使う最短のローカル構成。記事・既存TTS Studioと同じリポジトリの独立サブディレクトリに置き、公開サイトへは接続していない。

将来は管理者だけが生成・リアルタイム会話・試験を実行し、公開閲覧者は承認済みの録音と結果だけを再生する。閲覧者の操作でベンダートークンを消費させない。公開、認証・権限、公開用ストレージ、濫用防止、音声の公開権利・同意・プライバシー審査は未実装。現在のlocalhost制限を認証の代用として公開してはいけない。

## 現在の画面

モデル一覧からLive/TTSを選び、声と条件を指定する。Liveは自動発話検出または手動区切り、残り時間、停止、対話ログ、終了時の使用量・概算内訳を表示。TTSは短文を1回生成。モデル別履歴から録音・条件・文字起こし・JSONを確認する。

Geminiを優先し、登録IDは `lib/catalog.mjs` が正本。2026-10-11時点は `gemini-3.8-live`、`gemini-3.8-flash-tts`、`gemini-3.8-flash-lite-tts`。声はTTS/Live別リストのKore/Puck/Charon/Aoede。全声の実利用保証ではない。OpenAI Realtime / GPT Live / ElevenLabs / Cartesiaは無効なComing soon表示で、実装・接続・正式モデルIDの確認を意味しない。接続追加前に各社公式資料を再確認する。ElevenLabsは小規模の比較を想定。

Gemini 3.8 Liveのみ上部に公式料金とトークン例、下部に日本語・音声形式・VAD・割込み・コンテキスト・接続制限を掲載。他社への料金表の流用はしない。

## 録音の意味

ブラウザAudioWorkletの共通16 kHzサンプルクロックでマイクと描画済み再生音を記録する。`input.wav` / `output.wav` / `mix.wav` は同じ開始点・フレーム数。発話間の無音を詰めず、ミックスは各0.5ゲイン。割込みではキューを止め、未再生音をミックスに入れない。

`input-source.wav`は送信した入力の連結、`generated.wav`は受信した24 kHz出力の連結。後者には未再生音も含み、いずれも会話時間軸としては使わない。スピーカーの物理録音ではなく、OSミュート・Bluetooth遅延・耳に届いた音は測定しない。録音なしの場合はunavailableとし、受信音で代用しない。

停止で課金接続を閉じ、最大1.2秒だけローカル録音の末尾を待つ。欠損や終了フラッシュ不足は `recording.complete: false`。プロセスやPCの強制終了ではメモリ上の録音が失われうる。

## 使用量と概算料金

正本は `lib/cost.mjs` と[Google公式料金](https://ai.google.dev/gemini-api/docs/pricing)、[UsageMetadata](https://ai.google.dev/api/live)。2026-10-11確認のStandard有料枠、USD/100万tokensを使用する。入力TEXT 0.75 / AUDIO 3 / IMAGE・VIDEO 1、出力TEXT 4.5 / AUDIO 12。算式はモダリティ別tokens × 単価 ÷ 1,000,000。

使用量通知は原形保存し、通知別の取得済み内訳だけを小計表示する。通知が累積かターン値かをアプリが確証できていないため合算しない。prompt合計と内訳の差、thinkingの別計上・モダリティ、最終通知の完全性は未確認。thinkingを適当にTEXTへ割り当てたり二重加算しない。欠損はnull/不明、0 USDではない。セッション全体の `sessionUsd` はnull、`finalUsageConfirmed` はfalse。経過時間と録音時間は表示するが、課金音声時間へ換算しない。無料枠・契約・税・割引・実請求は未確認で、JPY換算もしない。

2026-10-11の保存済みユーザーセッションは経過53.870秒、録音52.536秒。通知は13.044秒と19.165秒時点に2件。小計はそれぞれUSD 0.00268650 / 0.00219075で、足し合わせない。最後までの総額は不明。これは請求額を確認した記録ではない。

## 起動・終了とデータ保持

起動コマンドと前提バージョンは[README](README.md)。`npm run mock`は外部API・キー・マイクなし、合成テスト音のみ。実接続の `npm start` も起動・ページ閲覧・履歴再生だけでは課金APIを呼ばず、生成/開始の人間操作で接続する。モードは画面上部とGET `/health` の `mock` を確認する。既定60秒、上限180秒、TTS90秒中止。同時1件、自動再接続・自動retryなし。時間制限は金額上限の保証ではない。

会話を画面で停止し保存完了を待ち、起動ターミナルでCtrl-Cを押してサーバーを終了する。過去にツールの実行セッション終了でサーバーも終了したため、開発中は手元ターミナルで起動し続ける。引き継ぎ時にエージェントが起動した切り離しプロセスが残っている場合、`lsof -nP -iTCP:8788 -sTCP:LISTEN` と `ps`、プロセスのcwdでこのアプリと確認してから、会話中でないことを確かめて終了する。無関係なプロセスをkillしない。OS常駐サービスは未設定。

`data/` はGitではバックアップされない。サーバー停止後、`data/`全体を本人が管理する安全な保存先へコピーする。音声とJSONを一組で保持する。既存履歴の自動削除・外部アップロードはない。会話内容や声を含むため公開するファイルは別途選定・承認する。

## 資格情報と課金承認

[CREDENTIALS.md](CREDENTIALS.md)が参照順・移行の正本。WKFL専用キーを `~/.secrets/wkfl/gemini-token` に中央保存し、値を文書・ログ・ブラウザ・Gitへ出さない。旧 `.env` は互換性のため保持しており、呼出元移行と実動作の確認後に人間が整理する。他プロジェクトに流用しない。

課金操作は人間の確認が原則。2026-10-11に例外承認されたLive接続1回は消費済み。無断の追加試験・一括声生成・大量実行・自動リトライをしない。今回の料金・仕様と文書更新は保存済みデータ、公式文書、無料のオフライン検証のみ。

## 確認状態と次の順序

- 実装済み：モデル画面、Live/TTSの接続経路、保存・時間軸録音、割込み処理、停止、履歴、Gemini Liveの料金・仕様と保守的な概算。
- オフライン検証済み：JS構文、モック接続・保存・制限・境界、既知タイムラインの無音/割込み/末尾/欠損、料金計算・欠損・重複通知の非加算。実音声品質の検証ではない。
- 実接続で確認：承認された1回でsetupと初回音声チャンク2バイトまで。ユーザー本人は実会話を試したと申告し、保存済み履歴がある。品質や全機能の成功を確認したとは扱わない。
- 実機未確認：全声、日本語品質、自然割込み、実スピーカーでの同期、TTS生成、料金UIの見え方。自動ブラウザはlocalhostをERR_BLOCKED_BY_CLIENTで拒否し、回避していない。

次は (1) 本人のブラウザで保存済み履歴と料金・仕様UIを確認（課金不要）、(2) UsageMetadataの通知範囲・thinkingと最終使用量を公式仕様または承認済み小規模試験で確定、(3) 必要なら対象・回数・時間・予算を合意して実機評価、(4) 共通台本と評価項目を整えて他社を追加、(5) 公開設計と権利/プライバシー審査、その後podcast/YouTube書き出し。公開・認証をこのローカルMVPが実装済みと扱わない。
